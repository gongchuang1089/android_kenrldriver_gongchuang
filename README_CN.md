# 安卓内核驱动

> 一个强大的安卓内核驱动，支持 Linux 内核 5.1 至 6.12（Android 12-16），通过自定义网络协议族提供高级内存操作能力。

## 🌟 功能特性

### 核心能力

| 功能 | 描述 | 技术实现 | 状态 |
|------|------|---------|------|
| **PTE 物理内存读写** | 直接访问任意物理内存地址 | 手动页表遍历 + PTE 重映射 | ✅ 已实现 |
| **PTE线性 物理内存读写** | 直接访问任意物理内存地址 | 手动页表遍历 + PTE 映射 | ✅ 已实现 |
| **进程内存读写** | 跨进程读写目标进程内存 | 使用 access_process_vm | ✅ 已实现 |
| **模块基址解析** | 获取目标进程已加载模块的基址 | VMA 遍历 + 文件路径匹配 | ✅ 已实现 |
| **进程发现** | 通过包名/进程名查找 PID | 进程遍历 + 名称匹配 | ✅ 已实现 |
| **自定义协议族** | 用户态与内核态安全通信 | 动态注册 socket 协议族 | ✅ 已实现 |
| **驱动隐藏** | 从系统各处隐藏驱动痕迹 | 链表删除 + kobject 移除 | ✅ 已实现 |
| **硬件 MMU 翻译** | 使用 AT 指令进行地址翻译 | ARM64 AT S1E0R 指令 | ❌ 未实现 |
| **触摸设备模拟** | 模拟触摸输入事件 | uinput/input 子系统 | ❌ 未实现 |
| 驱动自隐藏 | 从系统各处隐藏驱动痕迹 | 链表删除 + kobject 移除 | ✅ 已实现 |
### 技术亮点

- ✅ **多版本兼容**：支持 Linux 内核 5.1 至 6.12
- ✅ **ARM64 优化**：使用 `TLBI VAALE1IS` 指令硬件加速 TLB 刷新
- ✅ **完整页表遍历**：PGD → P4D → PUD → PMD → PTE
- ✅ **大页检测**：自动识别 1GB 和 2MB 大页
- ✅ **软件 TLB 缓存**：优化地址翻译性能
- ✅ **Normal-NC 映射**：缓存一致性的物理内存访问

```bash

# 2. 配置编译脚本
# 编辑 build_all.sh，设置以下变量：

./build_all.sh

# 4. 查看生成的内核模块
ls -la *.ko
```

### 安装

```bash
# 1. 推送到设备
adb push install_driver.sh /data/local/tmp/

# 2. 获取 root 权限
adb shell
su

# 3. 加载模块
cd /data/local/tmp/
./install_driver.sh
```

## 📖 API 文档

### 操作码列表

| 操作码 | 功能 | 参数 | 说明 |
|--------|------|------|------|
| `GET_PROCESS_PID` | 通过进程名获取 PID | 进程名 | 返回 PID |
| `ATTACH_PROCESS` | 附加到目标进程 | PID | 必须先附加 |
| `IS_PROCESS_PID_ALIVE` | 检查进程是否存活 | PID | 返回 1/0 |
| `GET_MODULE_BASE` | 获取模块基址 | 模块名 | 返回基址 |
| `ACCESS_PROCESS_VM` | 普通跨进程读写 | 地址和大小 | 使用内核 API |
| `PTE_PHYS_READ_MEMORY` | PTE 方式读取内存 | 虚拟地址 | 手动页表遍历 |
| `PTE_PHYS_WRITE_MEMORY` | PTE 方式写入内存 | 虚拟地址 | 手动页表遍历 |

## 🔬 工作原理

### PTE 内存读写流程

```
1. 用户空间发起请求
   ↓
2. Socket 通信传送到内核
   ↓
3. 获取目标进程 mm_struct
   ↓
4. 手动遍历页表 (PGD → P4D → PUD → PMD → PTE)
   ↓
5. 获取物理地址
   ↓
6. 修改 PTE 映射到目标物理页
   ↓
7. 刷新 TLB
   ↓
8. 直接读写映射后的虚拟地址
   ↓
9. 返回结果给用户空间
```

### 页表遍历详解

```
虚拟地址 (48-bit)
┌─────┬─────┬─────┬─────┬─────┬────────┐
│ PGD │ P4D │ PUD │ PMD │ PTE │ Offset │
│ 9bit│ 9bit│ 9bit│ 9bit│ 9bit│ 12bit  │
└─────┴─────┴─────┴─────┴─────┴────────┘
  ↓     ↓     ↓     ↓     ↓      ↓
 512   512   512   512   512    4KB
entries entries entries entries entries page
```

## 🔒 安全声明

### ⚠️ 警告

此驱动提供底层内存访问能力，可能：

- **绕过安全机制**：绕过 SELinux、Seccomp 等
- **导致系统不稳定**：错误的内存操作可能导致内核崩溃
- **被恶意利用**：可能被用于开发恶意软件
